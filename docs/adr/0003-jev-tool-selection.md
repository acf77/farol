# Jev selects a tool focus before each managed Chat turn

Managed Chat used to launch every coding CLI with its full default tool set. Jev already scored post-turn pipeline selection and step verdicts; it did not sit on the tool path. Narrowing tools per turn is the higher-leverage use of an evaluation model: less wandering, fewer irrelevant tools, and clearer policy — but only if uncertain scores never strand a coding turn or open Plan mode to writes.

We decided that before each agent invocation Farol asks Jev one **Choice** among host-prepared foci. Build mode chooses among `inspect`, `implement`, `verify`, and `answer`. Plan mode chooses only among read-only foci `inspect` and `answer` — inspection tools stay available (native `--tools` for Claude/OMP; prompt + provider review gates for the rest), and optional families (`edit`, `shell`, `web`) stay off. The host re-checks the returned id and candidates fingerprint before applying argv or a prompt clause. A Build focus applies only when the winning probability clears `JEV_TOOL_CONFIDENCE`; mid-band answers, unknown ids, fingerprint drift, timeouts, and missing keys fail open to the full tool set. Plan soft-fails to `inspect`, never to the full set. Provider review gates (Codex sandbox, Cursor ask mode, OMP inspection defaults) remain the hard Plan enforcement. Pipeline auto-selection remains a separate, permanent post-turn responsibility. Prompt-policy violations observed in tool cards are logged for diagnosis only in v1 — Farol does not kill the process mid-tool.

We rejected advisory-only injection (no real narrowing), shadow-then-enforce as the initial rollout (the product decision was immediate enforcement), failing closed when a provider lacks a per-run allowlist, removing pipeline auto-selection while building tool selection, auto-killing runs on the first omitted-family tool card, skipping tools entirely in Plan mode, failing Plan open to the full tool set, and one independent boolean per optional family (absolute Nouls do not compete the way a relative focus Choice does).
